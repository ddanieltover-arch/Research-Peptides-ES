## Quality bar

- No black-hat techniques
- Never break storefront functionality
- E-E-A-T and cite sources
- Mobile-first; WCAG 2.1 AA minimum
- Speed budget: page ≤ 3MB; avoid oversized JS bundles
- AI-first: “Would ChatGPT cite this?”

## This repo’s current phase focus

Technical foundation (Section 2 + crawl hygiene + schema dedupe + headers + llms) is the default first pass. Keywords, content/GEO expansion, and link building follow after the baseline in `seo/technical_baseline.md`.
